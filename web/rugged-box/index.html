Greg's Rugged Box

A Gridfinity rugged storage box with one fixed set of design choices, so every box and its bins match. The Greg preset is the filament-saving "Light" style: 1.2 mm floor, no interior border, thinner walls, three slim side ribs, no stacking plates, and a shallow front recess for label maker tape up to 24 mm.

Prebuilt kits

Each kit is one 3MF holding the bottom, top and latches as separate objects. Open in Bambu Studio needs Bambu Studio installed on this computer. After it opens, use Arrange, or split the parts across plates.
